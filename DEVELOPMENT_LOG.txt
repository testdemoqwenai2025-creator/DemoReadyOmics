================================================================================
 ARCHITECTURE SUMMARY
================================================================================
content/*.json (single source of truth)
    ↓ (lib/content.ts — build-time import + runtime GitHub raw API fetch)
React components render content
    ↓ (<a href={withBasePath("/path")}> — true MPA, full page loads)
Static export → CI smoke test → GitHub Pages → Demo2ReadyOmics

Pipeline YAML cards
    ↓ (sync_cards_to_content.py — validates against JSON Schema)
content/dataset-N.json
    ↓ (Next.js build)
Static export → GitHub Pages

Adding a dataset = edit a YAML file, run adapter, rebuild. No code changes.
Adding a customer story = edit content/customer-stories.json. No rebuild needed.
Changing pricing = edit content/pricing.json. No rebuild needed.
Schema evolves = publish dataset-card.v0.2.json. Downstream users pin to v0.1.
Regression introduced = CI smoke test blocks deploy.
