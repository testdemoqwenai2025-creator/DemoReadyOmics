The wedge

We don't compete with pipeline runners.
We compete on the handoff to ML.

Existing platforms (Nextflow, Terra, Galaxy, Seqera, AWS HealthOmics) are good enough at running workflows. Almost none of them ship datasets that are ready to train on. That handoff — from pipelines to ML — is where Tessera Bio is uniquely good.

U1

ML-ready outputs

Not just BAMs and VCFs — train-ready matrices.

Every pipeline emits a model-ready matrix plus a dataset card. Train / val / test splits are stratified by biological leakage (held-out donors, families, chromosomes, drugs), not random.

  • Leakage-controlled splits by default
  • Dataset card with full provenance
  • Quality metrics + failed-sample list
  • Suggested vs discouraged uses documented
U2

Identifier stability

When Ensembl or UniProt release, we tell you what broke.

Every dataset is pinned to a specific Ensembl release, UniProt release, and reference genome build. A built-in identifier-drift report flags genes added, removed, merged, or split between releases.

  • Pinned Ensembl / UniProt releases per dataset
  • Identifier-drift report on every release
  • Model-impact assessment: which models need retraining
  • Cryptographic provenance via Sigstore signatures
U3

Multi-omic harmonisation

Genes, transcripts, proteins, metabolites — first-class.

Most platforms handle one omic well and bolt the others on. Tessera treats genes, transcripts, proteins, metabolites, and pathways as first-class, joined, versioned citizens.

  • Common biological entity model across omics
  • Automatic join-key resolution
  • Unit and scale harmonisation
  • Per-source attribution pass-through
