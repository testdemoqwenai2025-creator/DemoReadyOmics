# Tessera Bio / ReadyOmics

**ML-ready, harmonised, version-controlled biological datasets for drug discovery and computational biology teams.**

Welcome to the public demo site for Tessera Bio / ReadyOmics. This site exists so prospective customers, partners, and investors can evaluate the product **without an NDA**, by reading the public positioning, schema, and worked examples here.

The internal code, pipeline implementations, and harmonisation layer live in a separate private repository. Anything you see on this site has been explicitly published for public view.

## What you will find here

- **[Positioning](positioning.md)** — what ReadyOmics is, what pain it removes, who it is for
- **[How it works](how-it-works.md)** — the one-way sync mechanism that keeps this public site a strict subset of the private repo
- **[Dataset Card Schema](dataset-card-schema.md)** — the machine-readable metadata format that ships with every ML-ready dataset
- **[Identifier Drift Report](identifier-drift-report.md)** — the format we use to flag what changes between Ensembl / UniProt releases
- **[Licence Matrix Summary](licence-matrix-summary.md)** — the public summary of which public data sources we ingest and under what licences
- **Demo Dataset Cards** — sample YAML files illustrating the metadata that accompanies a real dataset

## What is NOT here

- Source code for the pipeline or the harmonisation layer
- The dataset-card generator implementation
- Customer data or customer-specific configurations
- Commercial terms or pricing

For deeper technical evaluation, source-code access, or commercial discussions, please contact the Tessera Bio team directly.
